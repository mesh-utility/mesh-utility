# Mesh Utility Alpha-22

## Coverage map
- Zoomed-out coverage hexes now stop growing at about 19.5 miles (31 km) across, which they reach around zoom 7.5. Zooming out further keeps that same ground size, so coverage no longer merges into giant region-sized blobs.
- The on-screen shape limit never makes hexes bigger than that cap; when it applies, it keeps the shapes nearest the center of the view.

## Updating
- Alpha-19 and later can update from inside the app (Settings > App updates).
- Alpha-17 and Alpha-18 can't update themselves: install this APK once by hand, or use Obtainium.

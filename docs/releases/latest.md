# Mesh Utility Alpha-24

## Fixes

- The scan loop runs on your chosen scan interval again. The next discovery is scheduled from the previous due time, so a 40 second setting stays about 40.0 seconds apart instead of drifting longer. Changing the interval while scanning takes effect on the next cycle. The countdown only shows that timer; it does not move when discovery is sent or how long the app listens.
